Panduan Proses

1. Cek mutasi rekening, pastikan pembeli sudah transfer.
2. Ubah status dari PENDING ke PAID, lalu klik tombol Update Status.
3. Klik tombol Proses API (warna oranye) untuk menembak pesanan ke SMM Panel.
4. Klik Cek Status API (warna biru) secara berkala untuk memperbarui sisa pengerjaan dari SMM Panel.

Tarik semua layanan dari API SMM Panel Indonesia. Harga jual di web otomatis akan ditambahkan 30% (Markup) dari harga asli.
